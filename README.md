# 🎵 Spotify Clone

A simple **Spotify Clone** built using **HTML5** and **CSS3** as part of my frontend learning journey. This project recreates the landing page of Spotify with a clean and modern user interface. The main focus was to practice HTML structure, CSS styling, Flexbox layouts, hover effects, and responsive design concepts using media queries—without relying on JavaScript.

> **Note:** This is a static UI clone created for learning purposes. Buttons, links, and the music player are not functional.

## ✨ Features

* Spotify-inspired landing page UI
* Sidebar with Library section
* Navigation bar
* Album and playlist cards
* Bottom music player layout
* Hover transition effects
* Flexbox-based layout
* Responsive styling using media queries
* Built entirely with HTML and CSS

## 🛠️ Technologies Used

* HTML5
* CSS3
* Flexbox
* Media Queries
* Font Awesome

## 🎯 Purpose

I built this project while beginning my Full Stack Development journey to strengthen my understanding of HTML and CSS fundamentals. The goal was to improve my skills in creating modern layouts, organizing webpage sections, and replicating real-world website designs.

* Writing semantic HTML
* Creating layouts with Flexbox
* Styling responsive interfaces using media queries
